# BVP Solver — Универсальный решатель краевых задач

Программа для решения краевых задач (BVP) методом продолжения по параметру и методом стрельбы.

## Возможности

- Решение систем ОДУ с краевыми условиями
- Два метода: **продолжение по параметру** и **стрельба**
- Графический интерфейс на PyQt5 с интерактивными графиками (matplotlib)
- Поддержка загрузки/сохранения задач в JSON
- Интерфейс на китайском и русском языках

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```
