CHANGELOG
=========

v2.6 (2026-08)
- 将 GUI/JSON 外部表达式统一收口到受限 AST-to-SymPy 解析入口，不再使用 parse_expr 或自动创建未知对象
- 为 ODE、边界条件、辅助输出和 GUI 标量初值建立独立符号上下文
- 明确算术运算、数学函数、常量与 ASCII 标识符白名单，并拒绝名称冲突
- 在 SymPy 构造前拒绝属性、下标、Lambda、推导式、容器、字符串、任意调用和多语句输入
- 增加表达式长度、AST 节点、嵌套、数值字面量、函数调用和幂运算复杂度限制
- 新增带上下文、字段序号、错误码、截断预览和原因的 ExpressionValidationError
- GUI 在创建 worker 前显示表达式验证错误；辅助表达式失败继续逐项隔离
- 新增危险输入、合法语法、全部任务文件和离屏 GUI 安全回归测试及独立验收脚本

v2.5 (2026-08)
- 将 SymPyParser 唯一实现迁入 bvp_core.expressions，保持现有表达式行为
- 将 IVPIntegrationError 唯一实现迁入 bvp_core.exceptions，保留完整 IVP 诊断
- 将 BVPSolver 数值实现迁入 bvp_core.solver，算法、容差、分支顺序和结果字段不变
- bvp_core.api 删除对 main.py 的运行时延迟导入，实际求解不加载 main 或 PyQt5
- main.py 改为核心类兼容导入，Dataset 继续作为 GUI/JSON 适配层
- SolverWorker 继续使用不可变 SolveRequest，并统一调用公共核心 API
- 新增表达式、求解器、导入边界、旧入口兼容和唯一实现契约测试
- 第三阶段解析解、制造解和 ODE 数值一致性指标保持不变

v2.4 (2026-08)
- 新增不可变 SolveRequest、唯一 request_id 和来源快照
- 新增 SolveRecord 成功历史及结构化完成、失败和取消事件
- worker 信号绑定 request_id，过滤过期信号和重复终端信号
- 新增集中 GUI 求解状态、单活动请求守卫和协作式取消
- 窗口关闭时请求取消并有限等待，不使用 QThread.terminate
- 辅助输出、绘图和导出改用结果自身的问题与变量快照
- 不兼容跨任务结果默认隔离，辅助表达式失败保留逐项诊断

v2.3 (2026-08)
- 新增不依赖 GUI 生命周期的 bvp_core 公开入口
- 新增不可变 BVPProblem、SolverConfig 和 BVPResult 模型
- 明确区分问题定义错误与正常返回的数值求解失败
- 新增旧 Dataset/结果字典兼容适配层，GUI 和现有 JSON 字段保持兼容
- 数值验证脚本改用公开 API，解析解与制造解基线保持不变
- 记录过渡性技术债务：求解时仍延迟复用 main.py 中的解析器和求解器；第五阶段不扩大依赖，第六阶段再迁移

v2.2 (2026-08)
- 新增标量指数和简谐振子解析解测试
- 新增非齐次两状态制造解测试
- 新增未知参数、状态最大误差和 RMS 误差指标
- 新增独立边界回代与 Simpson 积分 ODE 缺陷指标
- 新增容差敏感性和重复性验证脚本

v2.1 (2026-08)
- 打靶法不再把优化器终止直接视为有效 BVP 解
- least_squares fallback 必须通过最终独立边界残差验收
- 参数延拓法不再在 Newton、Jacobian 或阻尼失败后无条件返回成功
- IVP 失败会保留底层状态、消息、积分终止位置和有限性诊断
- 边界条件与未知初值参数维数不一致会在调用 SciPy 前被拒绝
- GUI 不再把无效结果显示为绿色成功、加入有效历史、绘图或导出

v2.0 (2026-05)
- Интегрированная визуализация (IntegratedPlotWidget)
- Поддержка двух языков (китайский / русский)
- Библиотека задач с JSON-сериализацией
- Вспомогательные выходные переменные (aux_outputs)

v1.0 (2026)
- Базовая реализация метода стрельбы и продолжения по параметру
- PyQt5 GUI
- Парсинг уравнений через SymPy
