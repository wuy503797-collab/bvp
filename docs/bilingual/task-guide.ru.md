# Руководство по учебным задачам BVP Solver

[中文版本](task-guide.zh-CN.md) · [Двуязычный указатель](README.md)

Описание ниже получено непосредственно из текущих `examples/tasks/*.json`. Уравнения, краевые условия,
приближения и методы не восстанавливаются по старому отчёту или памяти.

## 1. Граница ресурсов задач

В `examples/tasks/` находятся пользовательские примеры для GUI/API: отдельные файлы 26.1–26.5 и
`textbook_problems.json` с задачами 26.1–26.4. `tests/fixtures/tasks/` содержит только намеренно
сингулярные или неверные по размерности входы негативных тестов и не рекомендуется пользователю.
Перенос ресурсов не изменил математику задач.

## 2. Задача 26.1 о двух телах

Файл: [`26_1_two_body.json`](../../examples/tasks/26_1_two_body.json). Состояние имеет вид

\[
(x,y,v_x,v_y),\quad x'=v_x,\quad y'=v_y,
\]

\[
v_x'=-\frac{x}{r^3},\quad v_y'=-\frac{y}{r^3},\quad
r=\sqrt{x^2+y^2}.
\]

Известны `x(0)=2`, `y(0)=0`, а в конце требуется

\[
x(7)=1.0738644361,\qquad y(7)=-1.0995343576.
\]

Неизвестны `vx(0), vy(0)`: два параметра и две компоненты невязки. В JSON заданы приближение
`[0.5,-0.5]`, `eps=1e-8`, `RK45` и 50 шагов continuation. Метод стрельбы и метод продолжения по параметру
могут прийти к разным траекториям, удовлетворяющим тем же краевым условиям. Текущие свидетельства не
перечисляют все ветви и не гарантируют сходимость из любого приближения.

## 3. Задача 26.2 о предельном цикле

Файл: [`26_2_limit_cycle.json`](../../examples/tasks/26_2_limit_cycle.json). Переменные названы
`x1,x2,x3,x4`, уравнения:

\[
x_1'=x_3x_2,\quad x_2'=x_3(-x_1+\sin x_2),\quad x_3'=0,\quad x_4'=0.
\]

Известно `x2(0)=0`; неизвестны `x1(0),x3(0),x4(0)`. Три компоненты невязки выражают
`x1(0)=x4(0)`, `x1(1)=x4(0)`, `x2(1)=0`. Начальное приближение `[2,6.283185,2]`, continuation имеет
100 шагов. В репозитории нет аналитической истины для этого примера, поэтому успех трактуется через
численную проверку и структуру задачи.

## 4. Задача 26.3 о тройном интеграторе

Файл: [`26_3_triple_integrator.json`](../../examples/tasks/26_3_triple_integrator.json). Шестимерная
система включает тройной интегратор и три сопряжённые переменные:

\[
x_0'=x_1,\quad x_1'=x_2,\quad
x_2'=\tfrac12\left(\sqrt{10^{-10}+(x_5+1)^2}-\sqrt{10^{-10}+(x_5-1)^2}\right),
\]

\[
x_3'=0,\quad x_4'=-x_3,\quad x_5'=-x_4.
\]

Заданы `x0(0)=1,x1(0)=0,x2(0)=0`, неизвестны `x3(0),x4(0),x5(0)`. При `T=3.275` требуется
`x0(T)=x1(T)=x2(T)=0`. Вспомогательный выход `u` совпадает со сглаженным управляющим выражением для
`x2'`. По умолчанию используется 50 шагов continuation.

## 5. Задача 26.4 о быстродействии в лунке

Файл: [`26_4_lunula.json`](../../examples/tasks/26_4_lunula.json). `x0,x1` — основные состояния,
`x2,x3` — переменные сопряжённого типа, а постоянное состояние `x4` масштабирует динамику на
нормированном интервале. Правая часть содержит нормировку `sqrt(x2**2+x3**2)` и сглаживание знака с
`1e-6`; полные выражения приведены в JSON.

Известны `x0(0)=4,x1(0)=1`; неизвестны `x2(0),x3(0),x4(0)`. На нормированном `T=1` требуется

\[
x_0(T)=0,\quad x_1(T)=0,\quad x_2(T)^2+x_3(T)^2=1.
\]

Приближение `[-0.54,-0.13,4.9]`, `eps=1e-6`, метод стрельбы. Малый знаменатель и сглаживание влияют
на численное поведение; аналитического решения в проекте нет.

## 6. Задача 26.5 о двумерном быстродействии

Файл: [`26_5_time_optimal.json`](../../examples/tasks/26_5_time_optimal.json). Состояние:
`x,y,vx,vy,psi1,psi2,psi3,psi4,T`. Конец независимого интервала JSON равен 1, а постоянное состояние `T`
является неизвестным масштабом физического времени: на него умножены восемь динамических уравнений,
и `T'=0`.

Известны `x(0)=y(0)=vx(0)=vy(0)=0`; неизвестны четыре сопряжённых начальных значения и `T(0)`. В конце
нужны положение `(1,1)`, нулевая скорость и условие трансверсальности из JSON:

\[
T\left(\sqrt{\psi_3^2+\psi_4^2}-\psi_3-2\psi_4\right)-1=0.
\]

Приближение `[0,0,1,1,3]`, `eps=1e-7`, 200 шагов continuation. Направление управления регуляризовано
через `sqrt(1e-10+psi3**2+psi4**2)`.

## 7. Негативные фикстуры

[`singular_ivp.json`](../../tests/fixtures/tasks/singular_ivp.json) использует `x'=1/(t-0.5)` и проверяет
передачу отказа задачи Коши при полюсе.
[`overdetermined.json`](../../tests/fixtures/tasks/overdetermined.json) имеет одно неизвестное начальное
значение и две компоненты невязки, проверяя отказ `unknown count != boundary residual count` до численного
запуска. Задача без вещественного корня `x(T)^2+1=0` строится тестом и доказывает, что завершение
оптимизатора не должно создавать ложный успех BVP.

## 8. Проверка при изменении задачи

Имена переменных, число ОДУ и карта начальных значений должны иметь одну размерность; число неизвестных
должно совпадать с числом компонент невязки; выражения должны проходить ограниченный AST-язык. Новый
пользовательский пример сохраняется в `examples/tasks/`, намеренно неверный автоматический вход — в
`tests/fixtures/tasks/`. Численная правка создаёт новый запрос и не должна менять кривую старого
`SolveRecord`.

## 9. Интерпретация свидетельств

Для 26.1 есть две проверенные численные ветви и явные конечные невязки, но нет перечисления всех ветвей.
У 26.2–26.5 нет аналитической истины, поэтому сопоставляются краевые невязки, конечность, согласованность
с ОДУ, повторяемость, чувствительность к методу и специальные ограничения задачи. Ни отдельное поле
`success`, ни красивый график, ни сообщение оптимизатора сами по себе не доказывают корректность.
