# Обзор проекта BVP Solver

[中文版本](project-overview.zh-CN.md) · [Двуязычный указатель](README.md)

## 1. Назначение проекта

BVP Solver — учебная программа для численных экспериментов с краевыми задачами для обыкновенных
дифференциальных уравнений. Она построена на Python, SciPy, SymPy, PyQt5 и Matplotlib. Текущая версия
проекта остаётся `v2.10`: отчётность Phase 12, реорганизация ресурсов Phase 13 и документация Phase 14
не добавляют новой численной возможности и не создают `v2.11`.

Программа содержит метод стрельбы, метод продолжения по параметру, GUI на PyQt5, безоконный API
`bvp_core`, ограниченный язык выражений, задачи JSON, сравнение нескольких результатов, метаданные
запуска и единый экспорт JSON/TXT. Это не производственный и не критичный по безопасности инструмент.

## 2. Текущее состояние и исторический снимок

Текущие документы описывают `main`: 307 тестов pytest, CI в Windows и Ubuntu, пользовательские примеры
в `examples/tasks/` и негативные фикстуры в `tests/fixtures/tasks/`. Исторический снимок v2.10 по-прежнему
связан с `2ac1a20`, а замороженный отчёт фиксирует 285 тестов своего периода. Современные факты нельзя
задним числом вносить в исторический отчёт, а исторические числа нельзя выдавать за текущий аудит.

## 3. Математический объект

Для системы первого порядка

\[
\dot{x}=f(t,x),\qquad x(t)\in\mathbb{R}^n,
\]

неизвестные начальные параметры `p∈R^k` дополняют начальное состояние. Определяется

\[
\Phi(p)=R\!\left(x(t_0;p),x(T;p)\right).
\]

Требуется решить `Phi(p)=0`. Число неизвестных параметров должно совпадать с числом компонент невязки
краевых условий. Совпадение размерностей не гарантирует существование, единственность, отсутствие
сингулярностей или устойчивость к начальному приближению.

## 4. Граница достоверного успеха

Итоговый успех не является синонимом статуса оптимизатора SciPy. Он требует четырёх групп свидетельств:

```text
success = ivp_success AND finite_success AND boundary_success AND algorithm_success
```

Кандидат проходит отдельное итоговое решение задачи Коши, проверку конечности, повторный расчёт исходной
невязки и покомпонентную проверку краевых условий. Безопасный синтаксический разбор доказывает лишь
принадлежность выражения ограниченному языку, но не интегрируемость ОДУ и не разрешимость BVP.

## 5. Инженерные возможности

- `bvp_core` не зависит от Qt или `main.py` и работает без GUI;
- `SolveRequest`, `SolveOutcome` и `SolveRecord` разделяют запрос, исход и исторические кривые;
- `run_id`, `request_id` и `problem_signature` связывают факты одного запуска;
- `bvp-result-v1` задаёт общий источник JSON/TXT, UTF-8, строгий JSON и атомарную замену;
- аналитические и сконструированные решения, негативные входы, допуски, счётчики и тесты GUI создают
  многоуровневую систему свидетельств;
- CI охватывает Windows, Ubuntu и эталонную среду Ubuntu с точными прямыми зависимостями.

## 6. Текущие ограничения

Китайская и русская версии совместно фиксируют следующие ограничения:

1. Jacobian по параметрам вычисляется прямой конечной разностью;
2. продолжение использует фиксированное число шагов и не реализует pseudo-arclength;
3. текущий отдельный вызов `solve_ivp` нельзя немедленно отменить;
4. для задач 26.2–26.5 нет аналитической истины;
5. задача 26.1 не перечисляет все ветви решений;
6. ODE defect не является строгой апостериорной оценкой погрешности;
7. GUI ограниченно редактирует расширенные допуски;
8. проект предназначен только для обучения и численных экспериментов;
9. проект нельзя применять в критичных по безопасности системах;
10. лицензия проекта пока не определена.

## 7. Языки и готовность к выпуску

Документация поддерживает `zh-CN` и `ru-RU`. В GUI уже есть словари и переключатель китайского/русского,
но аудит обнаружил жёстко заданные строки на китайском, русском и английском. Поэтому GUI лишь частично
двуязычен; полной i18n пока нет. В этой фазе GUI не изменяется.

Лицензия проекта пока не определена, поэтому `release_readiness_status=PENDING_LICENSE`. Это не дефект
кода, но до выбора лицензии проект не создаёт официальный tag или Release и не заявляет о передаче прав
на копирование, изменение или распространение.
